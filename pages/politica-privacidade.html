Política de Privacidade

Última atualização: 17 de agosto de 2026

1. Responsável pelo Tratamento

A Fireprin Lisboa Lda, com sede em Rua de Sevilha, Nº 5, 2605-868 Casal de Cambra, Portugal, é a responsável pelo tratamento dos dados pessoais recolhidos através do website fireprin.pt.

Contacto: 219 810 659 | geralfireprinlisboa@hotmail.com

2. Dados Recolhidos

O website da Fireprin recolhe apenas os dados estritamente necessários para o funcionamento das funcionalidades solicitadas:

  • Dados de contacto (nome, email, telefone) — apenas quando preenchidos voluntariamente através do formulário de contacto;
  • Dados de navegação — informações técnicas essenciais para o funcionamento do site (endereço IP anonimizado, tipo de navegador, sistema operativo);
  • Termos de pesquisa — termos de pesquisa no catálogo de produtos (processados localmente no navegador, não armazenados).

3. Finalidade do Tratamento

Os dados são tratados exclusivamente para:

  • Responder a pedidos de contacto e orçamentos;
  • Garantir o funcionamento técnico do website;
  • Melhorar a experiência de navegação do utilizador.

4. Cookies

O website da Fireprin não utiliza cookies de rastreamento ou analíticos. Utilizamos apenas uma cookie técnica (cookieAccepted) para registar a sua aceitação do aviso de privacidade, armazenada localmente no seu navegador.

Não existem cookies de terceiros, cookies de publicidade ou cookies de analytics.

5. Partilha de Dados

A Fireprin não partilha dados pessoais com terceiros para fins comerciais ou de marketing. Os dados podem ser partilhados apenas quando:

  • Exigido por lei ou autoridade competente;
  • Necessário para cumprir obrigações contratuais (ex: processamento de encomendas).

6. Segurança dos Dados

A Fireprin implementa medidas de segurança técnicas e organizativas para proteger os dados pessoais, incluindo:

  • Encriptação HTTPS/TLS em todas as comunicações;
  • Proteção contra ataques DDoS e WAF (Web Application Firewall);
  • Acesso restrito aos dados pessoais;
  • Monitorização regular de segurança.

7. Direitos do Utilizador

De acordo com o RGPD (Regulamento Geral de Proteção de Dados) e a LGPD, tem direito a:

  • Acesso — solicitar informação sobre os dados pessoais tratados;
  • Retificação — corrigir dados pessoais incorretos;
  • Apagamento — solicitar a eliminação dos dados pessoais;
  • Oposição — opor-se ao tratamento dos dados;
  • Portabilidade — receber os dados num formato estruturado.

Para exercer estes direitos, contacte-nos através de: geralfireprinlisboa@hotmail.com

8. Retenção de Dados

Os dados de contacto são mantidos apenas pelo tempo necessário para responder ao pedido. Os dados de navegação são processados em tempo real e não são armazenados em servidores da Fireprin.

9. Menores de Idade

O website da Fireprin não é direcionado a menores de 16 anos. Não recolhemos conscientemente dados pessoais de menores.

10. Alterações a Esta Política

A Fireprin reserva-se o direito de alterar esta Política de Privacidade a qualquer momento. As alterações serão publicadas nesta página com a data de atualização.
